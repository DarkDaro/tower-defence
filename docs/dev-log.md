# Журнал разработки — Tower Defence «Цитадель Орды»

Рабочие заметки: правила, решения, хронология изменений. Документация живёт здесь и в `README.md` / `td-project-description.md`, а не в комментариях кода. Актуальный список этапов — в `docs/state.md` (раздел «Этапы»), техописание — в `td-project-description.md`.

## Правила работы

1. **Ничего не удаляем.** Старая версия файла перед изменением архивируется в `Archive/`.
2. **Документация — в метафайлах отдельно** от кода.
3. **Описания коммитов** — короткие, на русском языке.
4. **Изменения кода — через скрипты** в `scripts/` (идемпотентные, с бэкапом), а не ручные правки.
5. Работаем сразу в `main`.

### 2026-11-02 — мобильный вид: зум и панорама

- Жалоба: «на телефоне нет нормального масштабирования, невозможно играть» — поле вписывалось в окно целиком
  (контейн 0.36 в ландшафте, 0.21 в портрете), клетки по ~20px, промахнуться пальцем проще, чем попасть.
- **Три режима вида в `resize()`** (game.js, ручки в `config.js → view`): десктоп — прежнее «contain», без зума,
  ноль регресса; **иммерсивный** (`pointer: coarse`) — враппер на весь экран (`body.immersive`, рамка и пульс
  выключены — анимированная тень на весь экран заставляла телефон перерисовывать окно каждый кадр), база —
  cover по ширине, если кроп по высоте ≤ `coverRatio` (1.45), иначе контейн; щипок растит канву до `zoomMax=3`;
  **портрет-поток** (≤700px портрет) — прежняя колонка панель/поле/мультиборд/панель, зум внутри клипа.
- **Панорама/зум:** pointer-события на канве (setPointerCapture): два пальца — зум вокруг середины щипка
  (pan = mid − o − v·k), один палец — панорама; клэмп панорамы не пускает за край (канва меньше окна — центр).
  Буфер не трогается во время жеста (плавно), резкий пересчёт через 150 мс после отпускания; DPR на таче капится
  `dprCapTouch=2` (филл-рейт на телефонах). Клик по клетке считается через getBoundingClientRect — сам учитывает
  и зум, и translate; после жеста клик гасится 350 мс (`suppressClickUntil`), иначе панорама строила башни.
- **Урок вёрстки:** мультиборд лежит внутри `.canvas-container`, и когда канва ушла в `position:absolute`
