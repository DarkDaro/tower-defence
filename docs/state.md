- Браузерная tower-defence «Цитадель Орды». Стиль: мрачное тёмное фэнтези (утверждено пользователем на спрайтах v2 — эталон для всего нового).

## Структура
- `index.html` — разметка UI: top-bar (ресурсы, спеллы), canvas-container (+multiboard), bottom-bar (кнопки башен + info-panel), оверлеи паузы/победы.
- `js/game.js` — вся игра: рендер, волны, башни, спеллы, сейв в localStorage.
- `css/style.css` — стили (палитра тёмного фэнтези: бордово-кровавая + латунь); `css/fonts.css` — локальные @font-face (Grenze Gotisch, Cormorant, Ruslan Display).
- `scripts/snap_enemies.py` — тестовый снимок «кадр+позиции» через `__TD` (agent-browser);
- `scripts/make_sprites.py` — генератор спрайтов: сетка 40×40, примитивы, passes outline+shade, экспорт ×4 (160px), превью `docs/sprites_preview.png`.
- `assets/sprites/{enemies,bosses,towers}/` — 32 PNG (16 врагов + 8 боссов + 8 башен).
- `Archive/` — старые версии скриптов.

## Ключевые константы (js/game.js)
- Поле: `VW=1792, VH=1008`; `CELL=56`; `COLS=32, ROWS=18`.
- Канва: буфер = размер на экране × DPR (cap 3, ширина cap 4200px), `setTransform` — резкость на любом окне.
- Панели absolute поверх канвы; канва = окно минус 24px (почти фуллскрин).
- Спрайты: PNG 160px → отрисовка 50px, 4-кадровая анимация (фаза = путь), fallback на процедурную живопись при ошибке загрузки. Соответствие ключ→файл: `TOWER_FILES`, `ENEMY_FILES`, `BOSS_FILES`.
