# Состояние проекта

Рабочий файл: читается перед любой правкой, обновляется в конце каждого чанка. Актуально на 2026-11-02. Роли доков: этот файл — «почему так» и текущее состояние, «Этапы» — роадмап, `dev-log.md` — хронология решений.

## Что это
- Браузерная tower-defence «Цитадель Орды». Стиль: мрачное тёмное фэнтези; эталон утверждён на спрайтах v2, от него не отходим.
- Всё своё, без внешних скачиваний: спрайты — генератор пиксель-арта, шрифты — локальные woff2, звуки — WebAudio-синтез.
- Стек: чистый JS (логика — один `js/game.js`, IIFE ~2250 строк; баланс — `js/balance.js`), CSS, HTML. Сборки нет.

## Запуск и проверка
- Сервер: `python3 -m http.server 8000` из корня репо → http://localhost:8000
- Тест каждой правки: в браузере — консоль без ошибок JS, волна идёт, постройка башни работает.
- Замер баланса: `python3 scripts/wave_run.py --waves 8 --speed 3 --plan scripts/plan_w1_8.json` (нужен поднятый сервер и headless-браузер).

## Структура
- `index.html` — разметка UI: top-bar (ресурсы, спеллы), canvas-container (+multiboard), bottom-bar (кнопки башен + info-panel), оверлеи паузы/победы; подключает конфиги в порядке `config → audio → balance → map → game`.
- `js/game.js` — вся игра: рендер, волны, башни, спеллы, сейв в localStorage.
- `js/config.js` — техручки (`window.TD_CONFIG`): поле/канва (VW/VH/сетка/кап буфера/DPR), спрайты (качество/кадры/размеры), тайминги цикла (скорости/автостарт/кап dt/тряска), таблица хоткеев (включая ЙЦУКЕН), ручки звукодвижка.
- `js/audio.js` — звук: пресеты `TD_SOUND` в шапке (каждый = массив слоёв tone/noise/chord/crackle/delay) + движок `TDAudio` (контекст/компрессор/буфер шума/троттлинг выстрелов).
- `js/map.js` — карта (`window.TD_MAP`): путь орды клетками, плотность/состав декора, шаг факелов, банки тумана — groundwork под вторую карту.
- `js/balance.js` — весь баланс (`window.TD_BALANCE`): старт/мана/спавн, экономика (апгрейды/продажа/награды/бонус), рост HP/брони, эффекты модов, заклинания, башни (включая спецы 4 ур.), враги/боссы, способности врагов (`abilities`), составы волн; метки и тултипы UI собираются из него же. Разбор и протокол круток — `docs/balance.md`.
- `css/style.css` — стили (палитра тёмного фэнтези: бордово-кровавая + латунь); `css/fonts.css` — локальные @font-face (Grenze Gotisch, Cormorant, Ruslan Display).
- `scripts/snap_enemies.py` — тестовый снимок «кадр+позиции» одним eval через `__TD`;
- `scripts/wave_run.py` — бенчмарк-забег волн с планом застройки: жизни/золото/убийства по каждой волне;
- `scripts/make_sprites.py` — генератор спрайтов: сетка 40×40, примитивы, passes outline+shade, экспорт ×4 (160px), превью `docs/sprites_preview.png`.
- `assets/sprites/{enemies,bosses,towers}/` — 32 PNG (16 врагов + 8 боссов + 8 башен).
- `Archive/` — старые версии файлов, `dev/` — копия старого монолита.
- `LICENSE` — некоммерческая лицензия (авторский проект; шрифты — OFL отдельно).

## Ключевые константы (техручки — js/config.js)
- Поле: `VW=1792, VH=1008`; `cell=56`; `cols=32, rows=18` (логика рисования — в game.js через CFG.view).
- Канва: буфер = размер на экране × DPR (cap 3, ширина cap 4200px), `setTransform` — резкость на любом окне.
- Панели absolute поверх канвы; канва = окно минус 24px (почти фуллскрин).
- Вид на таче (три режима в `resize()`): иммерсивный — поле по ширине (cover ≤ `coverRatio`), щипок до `zoomMax`, панорама пальцем внутри `.canvas-clip`; портрет-поток (порог `portraitPx`, CSS по классу `body.portrait-flow`) — прежняя колонка, зум внутри клипа; DPR на таче капится `dprCapTouch=2`. Клик после жеста гасится на ~350 мс.
- Спрайты: PNG 160px → отрисовка 50px, 4-кадровая анимация (фаза = путь), fallback на процедурную живопись при ошибке загрузки. Соответствие ключ→файл: `TOWER_FILES`, `ENEMY_FILES`, `BOSS_FILES`.

## Точки входа в game.js (строки приблизительные, файл ~2200; настройки — в конфигах js/{config,audio,balance,map}.js)
- `resize()` ~84 — три режима вида (десктоп/иммерсивный/портрет-поток), щипок-зум и панорама (pointer-события) рядом; `createTowerButtons` ~640; `getDifficultyMultiplier` ~684 (рост HP ×1.08).
- Спеллы: `castLightning` ~990, `castFrost` ~1013, `castFireRain` ~1032 (числа — из TD_BALANCE).
- `updateUI()` ~1105 — вызывается КАЖДЫЙ кадр: kill-list с кэшем, wave/stats/mana без кэша.
- `updateSelectedInfo()` ~1158 — перестройка innerHTML при выборе/улучшении.
- `drawScene` ~1448 — каждый кадр ставит трансформ буфера `canvas.width/VW` (НЕ DPR!); враги — по глубине, копия массива (порядок основного нужен прицеливанию).
- Метки кнопок: единые функции `pauseBtnLabel/soundBtnLabel/autoBtnLabel/hpNumBtnLabel/fsBtnLabel/speedBtnLabel` — все перезаписи innerHTML только через них (слова в `span.bname` — на ≤950px прячутся в топ-баре). Имена башен — `span.tname` (прячется там же). Новая кнопка = функция метки + min-width обоих состояний (десктоп и мобильный блок).
- Мобильный блок CSS: `@media (max-width: 950px)` в хвосте style.css; на тач (`hover: none`) hover-эффекты отключены.
- `loop` ~2148 — update(t), drawScene, updateUI, rAF. `__TD` ~2225 — тестовые хуки.
